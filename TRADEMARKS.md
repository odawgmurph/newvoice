You're welcome to fork, modify and ship this code. If your build differs from an official NewVoice release, give it a different name and icon.

This matters for safety as well as branding. NewVoice has fixed vocal-safety limits (warm-ups, session caps, strain stops). A modified build might change them, and users need to be able to tell the difference.

Referring to the project by name is fine, for example "based on NewVoice" or "a fork of NewVoice".
